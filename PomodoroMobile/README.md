# 手机版

最低支持 iOS 17。显示名称与电脑版统一为 PomodoroSwift，直接复用电脑版原生图标包。照片背景、三种表盘和玻璃面板保留电脑版视觉，布局适配手机。

## 当前功能

- 专注、短休息、长休息；暂停、继续、重置和时长选择。
- 数字、瑞士、鎏金彩晶三种表盘，在“设置 → 外观 → 表盘”切换；瑞士和彩晶的指针均按整段计时转一圈。
- 数字表盘沿用字形轮廓玻璃效果，可选择手机可用字体并调整字号。
- 鎏金彩晶复用电脑版三维几何、材质和着色程序；照片背景参与折射，按手机取景位置对齐。支持光线追踪的设备使用三维绘制，其他设备使用兼容绘制。退到后台时停止绘制。
- 手机独立选择照片背景、取景位置及表盘和按钮的玻璃样式。
- 「湖岸昼夜」背景随本地时间变化，支持清晨、正午、黄昏、深夜、月夜预览和亮暗配色。彩晶表盘可折射湖岸背景。
- 到时提醒支持从通知中开始短休息、长休息和下一段专注。专注完成后可停止或选择短、长休息，休息中可结束休息。
- 五种环境声：白噪音、粉红噪音、红噪音、雨声、篝火；支持音量、独立播放、仅计时播放，篝火有五种预设和十三项微调。
- 表盘大小、全局玻璃颜色、布局间距与重置；只读面板可在本机调整显示高度，背景支持照片或图片文件。
- 电脑待办单向同步：电脑发布，手机只读；面板可展开或折叠查看。
- 面板名称、任务顺序、置顶、亮暗配色以及「今日」归属和外观来自电脑。「今日」支持渐变和晴空，保留任务所在面板。手机不提供待办写入或面板管理入口。
- 不提供独立任务清单、专注记录、每日目标、周日程或数据导出。

旧版数据保留本机格式兼容，不会上载电脑。新版本不再生成专注记录。手机计时和背景设置保留。

## 连接电脑版

使用电脑版 1.1.7 构建 27，在“手机单向同步”中选择云盘文件夹；再在手机选择同一个文件夹。已有连接保留文件夹授权，升级后在电脑点「立即更新」，待云盘传输后在手机点「立即读取」。手机仅手动读取，电脑在修改保存后一秒写出或手动更新。详细步骤见 SYNC_PLAN.md，功能对应关系见 FEATURE_PARITY.md。

## 打开与验证

使用开发工具打开 PomodoroMobile.xcodeproj，选择同名运行方案及手机。

~~~sh
bash Scripts/check.sh
~~~

检查脚本核对两端同步协议和共用天空绘制源文件，运行核心及实际只读文件测试，并编译模拟器目标。另有真机表盘测试，验证字形、实际绘制、背景取景、资源和指针变化。

真机运行需要在本机的 `Config/Signing.local.xcconfig` 中设置 `DEVELOPMENT_TEAM`。

## 版本

1.6.0，构建 7。增加「今日」、湖岸背景和亮暗配色；旧照片、文件夹授权和待办缓存可继续使用。

iOS 26 及以上使用原生液态玻璃，较早版本使用系统材质兼容。
