# 手机与电脑版功能对应

手机版 1.6.0（构建 7），电脑版 1.1.7（构建 27）。待办保持单向只读，周日程暂不加入。

| 功能 | 手机对应实现 |
| --- | --- |
| 专注、短休息、长休息 | 三种模式和独立时长；每四次完成专注后推荐长休息 |
| 开始、暂停、继续、重置 | 已有；暂停时修改当前时长会重新准备该段，运行中修改不影响当前计时 |
| 专注结束后的操作 | 停止、短休息、长休息三项选择 |
| 休息结束后的操作 | 开始下一段专注 |
| 停止休息 | 返回待开始的专注模式 |
| 到时通知操作 | 通知中可开始短、长休息或下一段专注；忽略旧时段的通知，避免打断新计时 |
| 瑞士表盘 | 同源刻度比例、红色圆头单针；使用截止时间平滑更新进度 |
| 数字表盘 | 沿用电脑版字形轮廓玻璃效果，显示当前倒计时 |
| 鎏金彩晶表盘 | 复用电脑版几何、金属和晶体材质及着色程序，支持背景折射、动态指针和兼容绘制 |
| 自定义数字字体与字号 | 可搜索手机可用字体、预览并调整字号；缺失字体自动使用系统字体 |
| 表盘大小 | 可调，自动限制到手机可用宽度 |
| 白、粉红、红噪音 | 五类声音中的三种，采用电脑版的滤波算法 |
| 雨声、篝火 | 补齐；使用电脑版的声音层次与共振算法，加入确定性随机源、限幅及循环接缝处理 |
| 篝火预设 | 温暖壁炉、噼啪篝火、旺盛营火、余烬微光、柴火炉，参数与电脑版对应 |
| 篝火微调 | 十三项：低鸣、纹理、两类爆裂密度和音量、两类平滑度、三档频率、共振、连续爆裂概率 |
| 环境声音量及启停 | 独立控制；关掉后再次开启保留此前声音类型 |
| 仅计时播放 | 可关闭，环境声可独立播放及锁屏播放 |
| 玻璃样式、着色、透明度、触控光泽 | 手机可设置表盘和控制按钮的亮暗配色；待办面板沿用电脑的配色方案，使用湖岸背景时随时段切换 |
| 静态与动态背景 | 静态支持照片、纯黑与横向取景；湖岸昼夜支持实时与五种时段预览，并参与彩晶表盘的背景折射 |
| 今日面板 | 同步归属与外观，显示任务及原面板。支持自定义渐变和晴空；本机保留展开状态，可按本地时间或手动更新的位置计算天空 |
| 面板折叠、高度和布局重置 | 手机本机保存；可拖动面板底部把手调节高度，提供表盘与面板间距设置 |
| 电脑版浮动布局 | 手机采用纵向或横向自适应布局，不照搬桌面自由堆叠 |
| 数据同步 | 电脑修改保存后一秒写出或手动更新；手机手动读取，双方无定时检查 |
| 待办新增、编辑、置顶、排序、完成、删除及面板管理 | 按要求只在电脑完成；手机只读显示，不回写 |
| 人工智能分类录入 | 属于待办写操作，保留在电脑 |
| 周日程及日历叠加 | 按此前要求暂不加入 |

图标直接复用电脑版原生图标包，显示名称统一为 PomodoroSwift。手机旧背景、面板折叠、计时和同步目录授权在升级时保留。
